# Changelog

## 0.5.0 - Roadmap Implementation

- Split the calculator into engine, graphing, renderer, app, and tests.
- Added safe typed expression parsing with degree/radian support.
- Added Matplotlib graph windows with discontinuity-aware sampling.
- Added scientific features: factorial, reciprocal, percent, square, cube, absolute value, scientific notation, hyperbolic trig, log-base support, constants, and variables.
- Added editable expression/result display, inline errors, copy/paste, undo/redo, tooltips, help, dark mode, and integrated history/memory panels.
- Added CI, dependency metadata, packaging instructions, and release notes.

## 0.1.0 - Original Calculator

- Basic Tkinter calculator with arithmetic, memory, scientific buttons, and legacy graphing.
